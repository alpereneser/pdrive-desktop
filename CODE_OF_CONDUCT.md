# Contributor Covenant Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone.
Be respectful, assume good intent, give actionable technical feedback, and protect user
privacy. Unacceptable behaviour includes harassment, discrimination, threats, publishing
private information, and sustained disruption.

Project maintainers may remove or reject contributions and participation that violate these
standards. Report conduct concerns privately through the repository's maintainer contact or
GitHub abuse reporting. Maintainers will handle reports confidentially and proportionately.

This policy is based on the Contributor Covenant 2.1.
